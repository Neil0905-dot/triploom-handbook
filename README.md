# Triploom Handbook · 旅行手册

此文件夹包含 Skill 指令、完整四页应用模板、数据模型、默认资源与部署适配器。
安装后提供自己的 Excel、票据或文字行程，要求生成旅行手册即可。

今日、行程、账本、准备共享同一套数据。模板保留航班与酒店详情、地图、天气、
金额小数、个人承担／均摊、全部记录、滑动操作／撤销、个人清单和多人复制。
缺少可选资料时按规则处理，不能用删减功能的页面替代完整模板。

生成需要 Node.js 24+；XLSX 提取使用 Python 3 标准库；图片理解和浏览器检查
由宿主助手完成。这些运行环境不包含在 Skill 压缩包内。浏览成品不需要 Node。

入口是 SKILL.md。原始资料处理、缺失与冲突规则、数据格式、视觉要求、来源覆盖、
实际验收和部署方式分别放在 references 中。私人源文件和判断记录留在用户工程，
不进入公开 Skill；为该用户制作的插图也不进入通用包。

本地预览只在当前浏览器保存新增内容；CloudBase 和 Cloudflare 适配器用于各自
账号的共享部署。账号开通、登录、费用及公网访问必须按实际情况检查。同行口令
允许持有者共同编辑，成员切换不是独立身份认证。

包内自动测试验证具体能力，不代表所有原始文件、全部设备或真实云账号已验收。
历史测试的输入和答案不属于可复用知识，不放在这里。

## 使用名称

技术名称与安装目录均为 `triploom-handbook`，显示名称为「Triploom 旅行手册」。
安装后可以说：使用 $triploom-handbook，根据这份行程生成旅行手册。

## 安装

把这个仓库链接交给 Codex：

> 请从 https://github.com/Neil0905-dot/triploom-handbook 安装这个 Skill，然后使用它，根据我提供的行程生成旅行手册。

也可以下载仓库 ZIP，将包含 SKILL.md 的目录命名为 `triploom-handbook`，放到 Codex 的 skills 目录，再开启新任务。

## 3.1.0

- 世界地图标国家；国家轮廓图只标城市。景点仍在行程和导航中。
- 不再生成离线保存入口或“下一段旅程，慢慢准备”概览。
- 仅有抵达时间的航班按已知时间排入日程，住宿按当晚实际安排显示。
- 本地自动化覆盖四页交互及 320 / 390 像素视口；不代表任意输入或所有手机已通过验收。

内置轮廓为 Natural Earth 1:110m 公开地理数据。少数小国缺少轮廓，需要补充经核对的地图资源。
